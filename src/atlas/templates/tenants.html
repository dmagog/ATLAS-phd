Как добавить новую кафедру

Платформа спроектирована multi-tenant by design (M4.A). Чтобы запустить вторую/третью кафедру, нужно:

  1. Создать тенант: POST /tenants (slug + display_name)
  2. Загрузить программу: POST /tenants/{slug}/program (yaml/markdown)
  3. Загрузить материалы: через UI /admin tenant-admin'ом
  4. Раздать инвайты: POST /invites с role=supervisor/student

Domain-specific промпты, концептные словари, частные эвристики живут в per-tenant конфиге tenants.config — core-код не меняется.

Создать новую кафедру

Operations-flow: создание тенанта в production делается через CLI или прямой API. UI-flow для добавления кафедр в этом цикле не реализован (out-of-scope для одной-кафедральной защиты).

curl -X POST http://<host>/tenants \
  -H "Authorization: Bearer <super-admin-token>" \
  -H "Content-Type: application/json" \
  -d '{"slug": "math-kafedra", "display_name": "Кафедра математики"}'
